# 天枢智航城市无人机演示

Vue 3、TypeScript、Three.js 与 ECharts 实现的中文控制台。三维城市改造自 GitHub 的 [City Tour](https://github.com/jstrait/city-tour) 与 [THREEx Procedural City](https://github.com/jeromeetienne/threex.proceduralcity)，来源比较、改造范围与完整 MIT 许可见 [城市来源说明](../docs/city-sources.md)。所有无人机位置、事件、任务、指标和趋势来自后端快照。

## 运行

在项目根目录启动后端（默认 8011），然后在此目录执行：

```sh
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。Vite 将 `/api` 的 HTTP 和 WebSocket 请求代理至后端，可以用 `TS_API_TARGET` 覆盖后端地址。正式构建与事件适配器验证：

```sh
npm run test:scene-events
npm run build
```

生产部署需要代理 `/api`（包括 `/api/ws`）；单独运行 `vite preview` 不提供后端。场景所有纹理本地生成，不需要地图密钥、Cesium ion 或在线瓦片。

## 演示操作

1. 点击“创建 100 机演示”或选择一个单项事件，后端建立场景并保持暂停。已有运行状态不会被自动重置。
2. 启动仿真，完整演示依次触发拥堵、气象、故障和交汇冲突；单项场景还提供临时管制。
3. 三维城市提供总览、垂直俯瞰、近地视角、昼夜切换、镜头巡游、轨迹与标注。拖动旋转，滚轮缩放。
4. 点击无人机模型、鸟瞰小地图或右侧编号列表，跟踪单机并显示实际规划路径、状态与高度；“城市总览”退出跟踪。
5. “事件聚焦”开启时，新事件会定位实际影响区域、航路或单机。事件卡显示后端处置摘要；关闭聚焦仍保留事件提示，可手动定位。
6. 切换场景、重置时间、清空或更换城市会清理旧事件。暂停后可单步推进，报告导出保留实际指标与决策记录。

建筑的轮廓、位置、高度与后端避障模型一致，坐标由 ENU 米制 `(x,y,z)` 转为 Three.js `(x,z,-y)`。街道、绿化、灯具和地面车流用于视觉呈现；无人机模型随视距放大便于观察，不表示实物尺寸。未创建演示时显示静态城市预览，不生成虚构无人机或指标。

## 多方向交通

完整演示和五个单项 Demo 均按东、西、北、南分配任务；100 架时每个方向 25 架，24 机单项 Demo 每个方向 6 架，巡航高度依次为 150、210、270、330 米。不同方向采用分层走廊，邻近航线保持空间间隔，各任务拥有独立的落地点和真实可达的备降连接。城市只为实际起降点和备降点预留地面净空，高空航路点不额外清空楼宇，建筑仍参与真实碰撞检查。初始飞行进度按航线错开，仍由原有安全预测、避障、天气重规划和规则解脱推进。

机头按“0° 正北、顺时针”的后端航向正确转换，转弯沿最短角度平滑过渡；四旋翼增加机鼻轮廓和轻微转弯侧倾。垂直起降保留上一次水平航向，小地图箭头同步显示实际飞行方向。重新生成对应演示后生效。单项 Demo 的雷暴和管制区域根据实际在飞位置确定，保留可复现的事件时刻与真实撤离、改航和备降过程。

使用 `npm run test:flight-pose` 检查四个基本朝向、角度跨零和转向速率。

[四向交通效果截图](../docs/assets/four-way-traffic.png)。验证覆盖 72 项后端回归、23 项事件适配检查、航向转换检查和实际浏览器交互。seed=42 的 100 机完整演示在 436 仿真秒结束：99 架完成原任务、1 架完成备降，结束时没有剩余任务或冲突。

## 主要模块

- `scene/urban.ts`：实例楼宇、程序窗格、道路、公园、路灯、滨水与昼夜材质。
- `scene/traffic.ts`：四旋翼、实例旋翼、批量航路、真实轨迹和事件区域。
- `scene/eventFocus.ts`：后端事件的几何、摘要、定位以及跨场景清理。
- `components/CityScene.vue`：渲染生命周期、镜头、选机、小地图及事件提示。
- `stores/simulation.ts`：快照、HTTP/WS 初始化、重连及命令；断线保留最后状态。
- `scripts/test-scene-events.mjs`：基于真实后端事件快照的适配器测试。

实时协议为 `{type:"snapshot",sequence,data}`。后续快照省略 `environment` 时保留城市，显式 `null` 表示没有城市。九项运行统计的口径由后端统一定义，前端仅转换单位并舍入显示。
